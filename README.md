# 📜 Pāṇini's Master Manuscript Engine

> A high-end, 4th-grade accessible Sanskrit educational web app built with Python and Streamlit, bringing ancient Pāṇinian sūtras to life through interactive puzzles.

**Live Demo:** [https://panini-engine.streamlit.app/](https://panini-engine.streamlit.app/)

---

## ✨ Features

* **Interactive Word Constructor:** Step-by-step derivational breakdown transforming base seed words (*Upadesha*) into fully realized Sanskrit verbs.
* **Guess the Word Game:** Built-in challenge mode allowing students and enthusiasts to test their knowledge against real Pāṇinian linguistic rules.
* **Burgundy Glassmorphism UI:** A custom-styled, immersive dark-academia interface designed with a twilight burgundy gradient and responsive 3-column layout.
* **Simplified Linguistic Approach:** Kid-friendly terminology making ancient grammatical mechanics accessible and engaging for learners of all ages.
